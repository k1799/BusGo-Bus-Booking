# 🚌 BusGo – Bus Booking Web Application

BusGo is a web-based bus booking application designed to make bus searching, seat selection, and booking easier for users.

## 🚀 Features

- User Registration and Login
- Secure Authentication using JWT
- Bus Search and Route Details
- Seat Selection and Booking
- Booking Confirmation
- My Bookings
- Responsive User Interface

## 🛠️ Tech Stack

**Backend**
- Java
- Spring Boot
- Spring Security
- REST APIs
- Spring Data JPA / Hibernate

**Frontend**
- HTML5
- CSS3
- JavaScript (ES6)

**Database**
- PostgreSQL

**Tools**
- Maven
- Git & GitHub
- Postman
- VS Code
- NetBeans

## 🏗️ Project Structure

- `frontend/` – User interface files
- `backend/` – Spring Boot application
- PostgreSQL – Database

## ▶️ Getting Started

1. Clone this repository.
2. Configure your PostgreSQL database.
3. Update the database configuration in the backend.
4. Run the Spring Boot application.
5. Start the frontend using your preferred local development server.

**Note:** Database configuration and run commands may vary depending on your local setup.
